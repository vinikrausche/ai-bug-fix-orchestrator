# Skill: safe-bugfix

## Role

Developer.

## Purpose

Implement the Architect's plan with the smallest reasonable impact.

## Instructions

1. Read the bug context, project documentation, and FixPlan.
2. Follow the plan unless a blocking inconsistency is discovered.
3. Change only what is necessary to fix the issue.
4. Avoid refactoring outside the bug scope.
5. Preserve existing contracts and architecture.
6. Run relevant tests when available.
7. Keep all modifications visible through git diff.
8. Produce a short implementation summary.
