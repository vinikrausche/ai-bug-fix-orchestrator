# Skill: diff-review

## Role

Reviewer.

## Purpose

Verify that the implementation is minimal, correct, and consistent with the plan.

## Instructions

1. Read the original bug and FixPlan.
2. Inspect git diff.
3. Verify that the change addresses the reported problem.
4. Detect changes outside the intended scope.
5. Check compliance with project documentation and architecture.
6. Identify possible regression risks.
7. Report concerns clearly.
8. Do not modify source code.
