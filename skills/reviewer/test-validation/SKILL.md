# Skill: test-validation

## Role

Reviewer.

## Purpose

Validate the bug fix using the project's available tests.

## Instructions

1. Identify the project's test framework and test commands.
2. Prioritize tests directly related to the changed code.
3. Run a broader test suite when appropriate.
4. Record the commands that were executed.
5. Report passed and failed tests clearly.
6. Do not approve the review when relevant tests fail.
7. Do not modify source code to make tests pass.
