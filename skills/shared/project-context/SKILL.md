# Skill: project-context

## Purpose

Understand the minimum project context required before making decisions.

## Instructions

1. Inspect the repository supplied by the orchestrator.
2. Discover relevant project documentation, source files, and structure.
3. Identify files, modules, and rules related to the reported bug.
4. Treat discovered project documentation as a source of architectural constraints.
5. Use the existing codebase as evidence when documentation is incomplete.
6. Do not invent project rules that are not documented or observable.
